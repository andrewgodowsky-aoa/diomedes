The public entry offer is the 90-Day Workflow Starter: $299/month for 3 months, $897 total, with no extra Business subscription. It covers one supported workflow and remote setup; custom engineering and on-site work are separate. After 90 days, stop or separately agree the next scope. The wider ladder is a free fit call, audit from $1,000, pilot from $3,500, implementation from $5,000 and managed service from $750/month. Business software is planned from $199/org/month once operational. Billing, entitlements and operational managed service remain in development.

Local and in-person implementation is a first-class part of the business model when it materially improves discovery, installation, device/network validation, staff training, acceptance testing or go-live support. It is not free travel and is not required when remote delivery is sufficient.

Third-party software changes are an explicit operating risk. Managed Diomedes is partly the paid service layer for compatibility monitoring, smoke tests, configuration drift, triage and repair around named supported systems. It does not guarantee that outside vendors will never break an integration or create unlimited rebuild obligations.

The full prior roadmap, memory and pricing snapshots are retained under `docs/reference/`. Current source plus actual verification govern implementation; a planning document does not establish a shipped capability. No public site deployment or application implementation is implied by this documentation update.
