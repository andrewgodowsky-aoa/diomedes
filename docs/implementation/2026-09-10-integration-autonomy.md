## Bugs fixed (pre-existing on current main, reproduced before fixing)

1. Explicit document listing could return a stale in-flight walk
   (`server/store.ts`, `listDocuments`). A background refresh kicked at project
   creation could still be in flight when an explicit `/documents` call arrived;
   the old code returned that older walk's result. `backend.test.ts` (b)
   "SKIPPED_FOLDERS are never listed" failed deterministically after the
   3000-file test (a) (also failing on unmodified main and in the candidate
   tree; passing only when run alone). Fix: an explicit list awaits a pending
   walk, then walks fresh, restoring the documented "explicit list awaits a
   fresh walk" contract. Browser perf path (`/state`, SSE) is untouched; the
   200 ms / 3000-file bound still passes. One extra walk can occur only when an
   on-demand listing overlaps a background walk; no timers or processes added.
2. The `dispatched` abrupt-exit crash fixture raced the HTTP response
   (`tests/work-admission-child.ts`). The admitted 200 can be flushed before the
   generator's abrupt `exit(72)` wins, yielding exit 1 on a loaded host even
   though exactly one generation occurred (proven by instrumentation: one
   invocation, one exclusive-create write). The fixture now exits 73 on a second
   concurrent generator invocation (unsafe-redispatch detector), and after a
   200 in the `dispatched` phase it waits boundedly for the generator's marker
   and reports 72, failing loudly (stat timeout) if the generator never ran.
   Product dispatch behavior is unchanged; the `before`/`admitted` phases are
   untouched.
3. The legacy `scripts/desktop-smoke.mjs` assumed the old Workbook-first
   default; new profiles default to the Console (`surface: 'console'`). The app
   is correct (one-surface direction); the smoke now pins `surface: 'workbook'`
   for the Workbook lifecycle leg it was written to exercise (the Workbook still
   ships and must keep working). The Console packaged lifecycle is covered by
   the autonomy and app-update smokes.
