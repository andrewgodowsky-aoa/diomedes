# Diomedes 0.1.5

## Updates

- Adds the reviewed account-service and native sign-in prerequisites, including
  protected credential storage and packaged sign-in support.
- Adds reviewed inventory contracts, catalog/import preparation and stock-command
  calculations for later integration into authorized workflows.
- Adds workforce proposal constraints and scoped outcome-evidence calculations.
- Improves local durable-event recovery and removes fixed-delay assumptions from
  asynchronous regression tests.

## Limits

This is an experimental Windows build. The application and installer are unsigned.
Native sign-in still requires the deployed identity configuration and provider/OS
qualification before it can be offered as a working customer sign-in flow.
Inventory, scheduling and value calculations are prerequisites; this release does
not enable autonomous purchasing, guest messaging, kitchen devices or a complete
restaurant workflow. The personalized meeting displays remain labeled concepts.
Local event recovery does not certify remote tenancy or provider reconnection.

Release assets must be built and checked against the exact committed source.
