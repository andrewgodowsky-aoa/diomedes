WHAT IS NEW
  The Files pane works from the keyboard. The file tree was reachable only with a
  mouse before this build. It now takes a single tab stop and moves under the
  arrow keys, Home and End, with Enter and Space to open a file. Back returns
  focus to the row you came from rather than to the top of the pane.
  A preview that fails to load now offers an explicit retry instead of leaving an
  empty panel. Reads are cancelled when you move on, so a slow answer that lost
  its race is discarded rather than painting over the file you are looking at
  now. Deep folder hierarchies no longer widen the pane past its own scroll
  container: a twenty-level tree used to overflow by about 111 pixels at a 240
  pixel pane width. The pane keeps its state per project, so switching projects
  no longer carries the previous project's open folders and selection across.

  Streaming answers now belong to the run that produced them. Every piece of
  text the app shows while a model is still writing carries the run, step,
  attempt and lease it came from, and the app checks that it still owns the work
  before showing each piece. Before this build, text from a cancelled or
  taken-over attempt could still arrive and paint over a newer answer. Out of
  order, duplicated and gapped pieces are now discarded rather than shown.
  What you see while it types is not the record. If the connection drops, the
  app throws the partial text away and re-reads the saved answer instead of
  trying to stitch the stream back together. There is deliberately no replay of
  a live stream: see LIMITS.

  Cursor and Devin now run through one shared implementation of the agent
  protocol. Session setup, prompts, updates, permissions and cancellation are one
  piece of code with per-route configuration for how each is launched, how it
  signs in and what it can do, rather than two separate copies. Cancellation in
  particular now exists in exactly one place. Nothing about how you use either
  route changed.

  A dropped connection mid-answer now produces exactly one outcome. If a provider
  closes the socket partway through, the app records a single result that needs
  reconciling, invents no completion, and still shows that same single result
  after a restart. A dropped connection and a timeout are kept distinct.

UPDATES
  Settings > App updates offers stable releases only, and this is one. An
  installed 0.1.3 is offered this build when you press Check for updates.
  Nothing is downloaded, verified or installed until you confirm it, and a
  download is accepted only when its SHA-256 matches the digest the release
  publishes.

LIMITS
  Unsigned, experimental, one machine tested.
  Live streaming text is never replayed. It is not saved anywhere, so a reconnect
  re-reads the saved answer rather than the pieces that were in flight. If you
  lose the connection while a model is writing, you see the finished answer when
  it lands, not the part you missed. This is a deliberate limit and the app
  refuses to claim otherwise: the route's own contract marks that text as not
  durable, and a route that claimed it was would be rejected. Making it
  replayable across a restart would mean storing raw provider text as a durable
  record, which is a separate decision about retention and redaction and is not
  made here.
  No live engine turn was run on these bytes. Engine routes were last checked
  with one live turn each through the app's own local service, on commit
  b115b3c. Codex, oh-my-pi, Cursor and Devin were not live-tested on this build.
  The Design Center is in this build and behaves as it did in 0.1.3. Authoring
  inside the app is still developer-only, because the account and subscription
  software it depends on is not shipped yet. In an ordinary install you can open
  the Design Center, change things and watch the preview, while Apply, Save as
  new theme and Import do not work, and the screen says so. Authoring is
  switched on only by starting Diomedes with DIOMEDES_DESIGN_AUTHORING=1, which
  the included Start-Experimental.ps1 launcher sets.
  Appearance work is included in a Diomedes Business subscription and is done by
  our own design team: we build and install your first look, and you get one
  graphical update a month. There is nothing extra to buy.
  Connections runs on synthetic data only. The local service is loopback-only.
  There is no delete for a theme, and removing a picture from a theme leaves its
  bytes on disk.
