WHAT IS NEW
  A release candidate with account security repairs, kept engine
  conversations, account routing preferences and clearer work that needs your
  attention.

  Supported conversation engines keep their own sessions across follow-up
  messages, Stops and restarts. When an engine supplies a thinking summary,
  the conversation can show it above the reply.

  Personal Agent access and managed usage funding are checked separately. An
  Individual plan covers Personal work. Account routing preferences record the
  privacy profile you accept; managed calls require current access, funding
  and an eligible configured route.

FIXED
  Home links open the task or approval they name. Needs you counts approvals,
  changes awaiting review and failed work consistently across the Console.
  Review work is described as needing attention rather than requiring an OK.

  Account changes and sign-out cannot restore a stale session or borrow an
  admission made for another person. Streamed replies and thinking summaries
  redact secrets split across engine output chunks.

UPDATES
  This is a release candidate, separate from stable automatic updates.
  Existing project and settings locations are retained.

LIMITS
  This build is experimental. Windows builds are unsigned. Apple silicon
  builds use an ad hoc signature and are not notarized; Intel Macs are not
  included.

  The new account routing has not yet completed a real signed-in,
  paid-provider acceptance run. Automated routing journeys use synthetic model
  responses. A route without current qualification or required privacy consent
  stays unavailable.
