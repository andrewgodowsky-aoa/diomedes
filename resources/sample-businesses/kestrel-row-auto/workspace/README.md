# Kestrel Row Auto Repair

An independent four-bay repair shop on Kestrel Row in Millbrook. Service writer Luis Mendez runs the counter; four technicians. The shop system exports CSV files into `exports/` every night.

- `exports/` repair orders, estimates, invoices, parts orders, parts received and customers, as of Monday 2026-09-21 at 8:00
- `staff/` this week's technician schedule
- `notes/` the counter rules, the glass sublet log and Friday's pickup calls
- `owner-notes.md` what the owner wants answered
