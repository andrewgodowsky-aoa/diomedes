# Front counter rules

- Every estimate gets a follow-up if there is no answer **two hours** after it was sent. Text if there is a mobile number on file; otherwise call.
- Any job that will run more than $250 over its estimate needs a call before the work continues.
- When the work is complete, call or text the owner the same day and log it in that day's calls note.
- A repair order is closed only after the invoice is raised and paid.
- Northgate Parts Supply is first call for brakes, bearings and ignition. Beltway Auto Parts for HVAC. Glass is sublet to Crestline Auto Glass.
